# むぎの夜屋台 | Mugi's Night Stall — 収益化プロジェクト

セリフなしで、三毛猫が営む夜の屋台を描くショート動画。各話は単体で完結し、同じキャラが出続ける。全世界のショートフィードを狙う。

| ファイル | 内容 |
|---|---|
| `01_character_bible.md` | キャラ・世界観・画風の固定設定 |
| `02_content_calendar.md` | 14日分の投稿予定(ショート42本+長尺2本)と数字の判断基準 |
| `03_channel_setup.md` | チャンネル名、説明文、アイコン/バナー/サムネの生成指示 |
| `04_tools_and_workflow.md` | 契約するサービス、1本の作り方、あなたの毎日の作業 |
| `scripts/` | 全42本のカット割りと生成プロンプト |

## 先に知っておくべきこと

**1. 2週間での収益化は、狙うが確率は低い。**
調査では「新規チャンネルが2〜4週間で条件達成」という検証可能な実例は見つからなかった。AIショートドラマ新作の再生数は中央値で約2,900回という市場データもある。調査担当の主観的な見積もりは次のとおり。

| 目標 | 14日以内 | 30日以内 |
|---|---|---|
| 早期枠(登録500人+ショート300万回) | 3〜5% | 8〜12% |
| 広告収益(登録1,000人+ショート1,000万回) | 1%以下 | 3〜5% |

この計画は、その確率を上げるために組んである(言語不要、1日3本、型の違う3枠、数字による入れ替え)。条件達成後も審査に数日〜約1か月かかるため、「2週間で入金」にはならない。

**2. 期限が実際にある: 2027年1月31日。**
2027年2月1日以降の新規申請は基準が上がる(登録1,000人+年間8,000時間またはショート2,000万回)という公式ヘルプの記述が検索結果で確認された。それまでに申請すれば現行基準。今日から約10週間が本当の勝負期間になる。数値はYouTube公式ヘルプで必ず確認すること(調査環境から公式ページ本文を直接開けなかった)。

**3. 現行の条件(従来基準。公式で要確認)**
- 早期枠(スーパーサンクス、メンバーシップ等): 登録500人、90日以内に公開3本、ショート300万回(90日)または3,000時間
- 広告収益: 登録1,000人、ショート1,000万回(90日)または4,000時間
- 共通: 2段階認証、AdSense連携、ガイドライン違反警告なし

**4. 審査で落ちる型を避ける。**
YouTubeは2025年7月と2026年7月に「テンプレ的・反復的なAI量産」「不快な内容」「AIペルソナによる健康・金融の話」を収益化対象外と明確化した。この企画は、固定キャラ・毎回違う脚本・視聴者リクエスト反映で、人間の創作関与を見える形にしている。

## ジャンル選定の理由
- 条件を最速で満たす経路はショート再生数。言語不要の映像は視聴者の母数が最大
- 日本語の雑学・2ch系・解説系は飽和しており、AI音声解説は取り締まりの標的に近い
- 猫×料理×日本の夜景は海外でも通じる。固定キャラは登録の理由になりうる(未実証)
- ショートの収益単価は低い(米国で1,000回あたり約0.08〜0.33ドルという二次情報)。収益の柱は将来の長尺総集編とファン機能と考える

## 検証結果(2026-11-22)— 企画のどこにデータの裏付けがあるか

初版の企画を、反証を探す前提で再調査した。新規チャンネルの最初の30日の成長記録は1件も見つからず、多くの出典はツール販売会社のブログだった。

| 要素 | 判定 | 根拠 |
|---|---|---|
| AIの猫・動物キャラのショート | **裏付けあり** | AI動物チャンネルが世界の上位に複数(Kapwing調査)。赤い子猫のAIチャンネルが約60万人・5億回超との報道 |
| ミニチュア料理 | **裏付けあり** | 実写のミニチュア料理チャンネルが登録145万〜267万人で複数存在 |
| 猫が料理するAI動画 | 弱い裏付け | 84本で登録100万人超、93本で約270万人という記述(出典の質は低く、古い)。2026年末も伸びているかは不明 |
| セリフなし | 未検証 | 利点を示すデータなし |
| 連続ドラマ形式 | **未検証、不利の可能性** | 有利とする記述はベンダーの主張のみ。ショートは文脈なしで見られるため、単体で成立しない話は不利になりうる |
| 羊毛フェルトのストップモーション風 | **未実証** | 伸びたAIフェルト動画は確認できず。実写のフェルト作家は登録4万〜12万人規模。伸びないという証拠もない |
| 登録への転換 | 低い | ショート一般で1,000再生あたり1〜4人という目安(ジャンル固有値は不明) |

### これを受けた修正
1. **画風の標準を「かわいいAI猫 × 本物に見えるミニチュア料理」(STYLE A)に変更**。フェルト風(STYLE B)は比較用に残した。台本から画風の語を抜き、`[STYLE]` の差し替えだけで切り替えられる
2. **各話を単体完結として扱う**。物語回の最後の「次回への引き」カットは、伸びが確認できるまで省いてよい
3. **裏付けの強い料理ASMR(B枠)を主力にする**。初週は B枠2本+A枠かC枠1本
4. **最初の3日間は比較テスト**: M1〜M3 を STYLE A と STYLE B の両方で作り、計6本を投稿。視聴継続率と再生数で勝った方に統一する

### 登録者の現実的な計算
1,000再生あたり1〜4人なら、登録500人には12万〜50万再生、1,000人には25万〜100万再生が要る。条件の厳しい側は再生数(300万回/1,000万回)であり、登録者ではない。

## やらないこと
再生数や登録者の購入、相互登録、他人の動画・音楽の転載、切り抜き。チャンネル停止か審査落ちになり、目的を潰す。

## 最初の3日でやること
1. `04_tools_and_workflow.md` のサービスに登録する
2. `03_channel_setup.md` のとおりチャンネルを作る
3. むぎの参照画像を STYLE A と STYLE B で1枚ずつ作り、M1〜M3 を両方の画風で制作して投稿する(比較テスト)
4. 48時間後の数字(視聴継続率、平均視聴率)をこのセッションに貼る。こちらで差し替え案を出す
