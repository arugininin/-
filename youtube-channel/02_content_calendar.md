# 14日間の投稿カレンダー(ショート42本+長尺2本)

1日3本。種類を変えて「同じ型の量産」に見せない。投稿時刻は日本時間。

- **A枠 物語回(本編)** 30〜40秒 / 21:00 … 連続ドラマ。登録の動機を作る主力
- **B枠 今夜の一品(料理ASMR)** 16〜24秒 / 12:00 … ループ再生と保存を狙う
- **C枠 小ネタ(ギャグ)** 10〜16秒 / 18:00 … 共有とコメントを狙う

タイトルは「英語の短文+絵文字 | 日本語」。説明欄の1行目は英語、ハッシュタグは `#shorts #cat #stopmotion #cooking` を基本に回ごとに1つ足す。

台本(カット割りと生成プロンプト)は `scripts/` 配下。
