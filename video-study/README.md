# 動画学習セッション 引き継ぎ書

このフォルダは「ユーザーが面白いと思ったYouTube動画から、構成と編集の型を学び、制作中の各セッションへ反映する」ための作業場所。PC上で新しく開いたセッションは、まずこのファイルを読んで続きから始める。

## 目的
1. ユーザーが送る動画(URL+面白いと思った点)を分析する
2. 動画ごとの分析メモと、共通する型をまとめた手引きを残す
3. 手引きをもとに、反映先のセッションへ具体的な指示を出す

## 学習対象の分類
- **A ゆっくり実況・ドラクエ関連**: 内容と編集の両方を学ぶ
- **B ドラクエ関連で人が喋る動画**: 編集を学ぶ
- **C 無関係な動画**: 編集の技法だけを学ぶ(ジャンル不問)

## ファイル構成(動画が届いたら作る)
- `notes/<日付>_<動画ID>.md` … 動画1本ごとの分析メモ
- `style_guide.md` … 共通する型をまとめた手引き(学習内容の本体。セッションは記憶を持ち越せないので、ここに書いたことだけが残る)
- `handoffs/<反映先>_<日付>.md` … 各セッションへ出した指示の控え

## 分析メモに書くこと
- 基本情報: URL、チャンネル、尺、分類(A/B/C)、ユーザーが面白いと言った点
- 構成: 冒頭15秒のつかみ、展開の区切り(時刻つき)、オチと締め
- 話し方: 掛け合いの間、ボケとツッコミの比率、一文の長さ
- 編集: テロップ(出し方、色、大きさ、位置)、カットの間隔、効果音とBGMの使い分け、ズームや揺れ、画面構成
- 視聴者の反応: コメントで言及の多い場面と時刻
- 持ち帰る型: 他の動画でも使える形に一般化した手法(3〜5個)
- 確認方法: 字幕だけで判断したのか、映像を見て判断したのかを項目ごとに書く。見ていないものを見たように書かない

## 守ること
- 移すのは技法と型。他の投稿者の台詞、ネタ、素材、音楽はそのまま使わない
- 反映の指示は、ユーザーが指定したセッションにだけ出す。指定がなければユーザーに聞く
- 根拠のない「伸びる」という断定をしない。数字がある場合だけ数字で言う

## これまでの経緯(クラウド側セッションから)
- クラウド側では YouTube 本体に接続できず、映像を見られなかった。PC上のセッションなら映像の確認ができるので、編集の分析はPC側で行う
- YouTube取得用プラグイン TubeAlfred は、クラウド側では認証エラー(401)で未接続のまま。PC側で使えるかは未確認
- YouTube Data API キーは、PCのユーザー環境変数 `YOUTUBE_API_KEY` に登録する手順をユーザーに案内済み(登録が済んだかは未確認)。値は表示・送信しない
- 関連セッション: 「DQ攻略動画」「DQ10宝珠サイト」「ずんだもんたち(IPA)」ほか。DQ攻略動画には別件の集計依頼(16ジャンルの再生数調査)が承認待ちで残っている。不要ならユーザーが取り消す
- 同じリポジトリの `youtube-channel/` は、保留中の別企画(猫の屋台ショート)。この学習作業とは別物

## 最初にやること
ユーザーに、動画のURL、面白いと思った点、反映先のセッション名を送ってもらう。
